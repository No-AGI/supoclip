# Карта автоматизации контент-фабрики (2026-11-17)

Цель владельца: источник → анализ → отбор → монтаж → перевод → субтитры → обложка → описание → QA → пакет публикации, с минимумом рук. Здесь по каждому звену: что уже проверено, что строится, что отложено и что отклонено. Статусы: **BUILT** (работает и проверено), **NEXT** (следующий шаг, оценка есть), **DEFER** (нужны данные/деньги), **REJECT** (не делаем и почему).

## 1. Поиск источников

- **BUILT (частично):** `stream_source.py` качает YouTube, выбирает аудиодорожку, сохраняет сайдкар транскрипта.
- **FACT:** на `JsTO6t5GImY` у ролика две дорожки — русская и `en-US` автодубляж. `bestaudio` выбрал русскую по битрейту (114 против 105 kbps), то есть **случайно**. Это дефект: язык должен решаться явно.
- **NEXT:** правило выбора дорожки по языку из настроек, а не по битрейту; отказ от автодубляжа, если он дублирует оригинал.
- **DEFER:** поиск новых источников по каналу/тегам — нужен API и лимиты; сейчас не строится.

## 2. Детекция моментов

- **BUILT:** речевой канал (`speech_events.py`), визуальный канал (`visual_events.py`), окно сканирования, дедупликация по кадрам, объединение с приоритетом речи.
- **FACT (измерено на 15 минутах стрима, разметка независимая):** речь 0.323 recall / 0.909 precision, зрение 0.129 / 0.667, вместе 0.419 / 0.929.
- **Вывод:** зрение — только резерв (`VISUAL_CANDIDATES_ENABLED`, выключено по умолчанию).
- **NEXT:** событийная разметка без речи (перестрелка, погоня, физика) требует признаков, которых нет в речи: детектор движения по кадрам уже есть, но точность 0.67 на 6 кандидатах — этого мало для автопубликации, хватает для подсказки человеку.
- **DEFER:** мультимодальная модель на кадрах (local VLM или платный vision) — не проверено, стоит денег; до появления бюджета не строится.
- **REJECT:** PySceneDetect / TransNetV2 / YOLO как зависимости. Причина: сегодня всё сделано на ffmpeg + numpy, работает на CPU без CUDA; новые зависимости ломают AMD-сборку и требуют пересборки образов.

## 3. Сравнения и сплит-скрин

- **DEFER.** Требует второго источника и выравнивания по времени/сцене. Ни одного замера нет, поэтому обещать нечего. Первый шаг, когда появится второй материал: ручное сравнение двух кадров и проверка, что кроп 9:16 не режет обе половины.

## 4. Вертикальное кадрирование

- **BUILT (измерение):** `vertical_preview.py` — замер центра движения, рендер превью 9:16.
- **FACT:** на окне 112.3–132.3 с центр движения 0.502 ± 0.088, кроп 608×1080 покрывает 31.7% исходных пикселей; текущий blur-fit в рендерере занимает ≈32% площади.
- **FACT (Reels 2026-11-17):** статичный кроп 405×720 с x=430 дал 1080×1920 без веб-камеры стримера — но это ручной выбор смещения, а не траектория.
- **NEXT:** подключить `build_crop_trajectory` к рендереру вместо статичного кропа, с проверкой на тряску.

## 5. Субтитры

- **BUILT:** выжигание из платного транскрипта через ASS, русский, перенос по ширине.
- **FACT (два дефекта, найдены и исправлены):** неполное поле `Format` в `[Events]` съедало первый символ реплики (возвращался как «,»); `WrapStyle: 2` обрезал длинные строки по краям.
- **NEXT:** перенос строк по слогам вместо ширины, чтобы не рвать слова; проверка на кодировку при вычитке.

## 6. Обложки и карусели

- **BUILT:** `cover_render.py` (1080×1920) и `carousel_render.py` (1080×1350), 11 тестов.
- **FACT:** Archivo Black, Bebas Neue, Poppins и League Spartan не содержат кириллицы; рабочий шрифт — Montserrat 900.
- **FACT:** веб-камера стримера живёт в левом нижнем углу, кроп по умолчанию 0.62 её исключает; проверяется тестом по красным пикселям.
- **NEXT:** выбор кадра и текста по разметке событий (сейчас делает человек).

## 7. Перевод и описания

- **DEFER, заблокировано.** Анализ транскрипта упирается в LLM: единственный ключ Google отклоняется (`API_KEY_INVALID`), бесплатная квота OpenRouter исчерпана (`free-models-per-day`). Лимит вывода сделан настраиваемым (`LLM_MAX_TOKENS`), но квоту это не возвращает.
- **FACT:** `openrouter/auto` отклоняется как `Unknown model`; из бесплатных моделей сегодня отвечали `inclusionai/ling-3.2-flash:free` и `particle-ai/particle-1:free`.

## 8. QA и пакет публикации

- **BUILT (частично):** `crop_checks` проверяет оба кропа контракта; тесты проверяют размер, кириллицу, веб-камеру, длинные подписи.
- **NEXT:** единый манифест пакета (обложки + карусель + Reels + описание + хештеги) с хешами и отметкой «GTA IV», чтобы нельзя было опубликовать как GTA VI.
- **REJECT:** автопубликация в Instagram. Публикация — отдельное разрешение владельца, всегда.

## 9. Аналитика

- **DEFER.** В продукте есть снимки метрик по платформам, но обратной связи «какой тип момента зашёл» нет: без неё оптимизация отбора была бы гаданием.

## Экономика

- **FACT:** один прогон AssemblyAI на 63 минуты дал 8494 слова за 2.5 минуты; повторный прогон **без** `checkpoint_callback` снова списал деньги, потому что отпечаток содержимого считается только при наличии коллбэка. С коллбэком — `assemblyai_calls=0`.
- **Правило:** любой скриптовый прогон обязан передавать коллбэк чекпоинта, иначе кэш не спрашивается.
