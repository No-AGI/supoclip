# Обложки из кадра: как устроено и что проверено

`backend/src/media/cover_render.py` собирает обложку 1080×1920 из кадра стрима и типографики по контракту из `04_COVER_CONTRACT.md`: две строки заголовка (белая и розовая), розовый разделитель, жёлтый ник и розовое подчёркивание в CTA. Никаких платных сервисов и никакого ручного дизайна — только Pillow.

## Входы

`render_cover(frame, out, white_line, pink_line, cta, crop_offset, font_name, font_weight, shear, dim)`

- **кадр** — любой PNG из исходника; масштабирование идёт по высоте, затем берётся кроп 9:16;
- **crop_offset** — доля свободного хода кропа вправо. Веб-камера стримера живёт в левом нижнем углу, поэтому по умолчанию 0.62;
- **font/weight** — по умолчанию Montserrat variable 900. Это не вкус: Archivo Black, Bebas Neue, Poppins и League Spartan не содержат кириллицы и рисуют русский текст квадратами;
- **shear** — наклон слоя заголовка (0.20). После преобразования слой центрируется по фактическим чернилам, иначе нижняя строка уходит за край.

## Что делает код

1. масштаб по высоте → кроп 9:16 по `crop_offset`;
2. `UnsharpMask` для апскейла с 720p;
3. затемнение сверху и снизу: белый текст должен читаться и на светлом небе, и поверх HUD;
4. заголовок рисуется на отдельном RGBA-слое с обводкой 10 px, затем наклоняется целиком;
5. розовая «кисть» под заголовком: три перекрывающихся скруглённых прямоугольника, лёгкое размытие — силуэт не выглядит капсулой;
6. CTA: `ПОДПИШИСЬ • @GTAVI.FRAME`, розовая точка между словами, жёлтый ник, розовая линия под ним. Размер шрифта подбирается так, чтобы блок занимал не больше 90% ширины, а базовая линия стоит на 0.855 высоты — ниже начинается интерфейс Reels.

## Что проверено тестами

`backend/tests/unit/test_cover_render.py`, 6 тестов, требуют Pillow (иначе `importorskip`):

- размер ровно 1080×1920 и соотношение 0.5625;
- оба кропа из контракта (3:4 и 4:5) сохраняют соотношение;
- у шрифта по умолчанию есть настоящие кириллические глифы (разные ширины, не `.notdef`);
- красный блок веб-камеры в левом нижнем углу исходника не попадает на обложку;
- разные `crop_offset` дают разные кропы;
- длинный заголовок не рисует чернила в крайних 6 столбцах.

## Ограничения

- 720p-исходник даёт апскейл ×2.67; для сторис приемлемо, для печати нет;
- подбор кадра и текста не автоматизирован: код не знает, что происходит в кадре, и не придумывает заголовок. Это следующий шаг — связка с разметкой событий из `visual_events`;
- игровые субтитры в нижней трети не удаляются: кадр надо выбирать без них либо закрывать полосой, что пока не сделано.
